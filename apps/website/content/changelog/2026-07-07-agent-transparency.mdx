### New

- **Beat detection.** Ask the agent for a montage cut to the music and it can
  now find the beats, it analyzes your audio and gets back every beat plus the
  song's tempo, so cuts land on the rhythm instead of near it.
- **A live to-do list.** Ask the agent to plan first and its plan appears
  immediately as a checklist, you watch each step light up while it runs and
  check off as it finishes, so you always know where the run stands.
- **A closing report.** When a run finishes, the agent sums up what it changed,
  what it skipped, and why, no more scrolling back through the activity to
  piece together what happened.

### Improved

- **The agent talks you through the work.** Its explanations now appear as
  chat messages right between the actions they describe. "trimming the silent
  gaps now…" followed by the trims, instead of being tucked into a side panel.
- **Honest activity cards.** Every analysis step shows a live timer while it
  actually runs, tells you exactly what it was asked to do, and shows how long
  the real thinking took.

### Fixed

- **No more phantom checkmarks.** Analysis steps used to show as done
  instantly, even when nothing had run. They now run for real, and pressing
  Stop marks the interrupted step as stopped, never as completed.
- **Zooming with thumbnails on is smooth again.** The timeline filmstrip no
  longer re-decodes its images on every zoom tick, so pinch-zooming a big
  project stays fluid instead of freezing the app.
- **Tidier collapsed panels.** A collapsed side panel is now a slim, quiet
  edge that glides open and closed, without a leftover drag handle beside it.
