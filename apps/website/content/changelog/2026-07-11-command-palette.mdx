### New

- **Quick command palette (⌘K / Ctrl+K).** Press ⌘K anywhere in the editor to
  open a command palette. Select a clip first and type what you want changed —
  "tighten this up," "make the cut punchier" — and it's sent straight to the
  AI as an edit scoped to that clip, no need to open a chat first.
- **"Ask AI about this clip."** Right-click any clip on the timeline for a new
  "Ask AI about this clip" option. It selects the clip and opens the same quick
  command palette, already scoped to that moment — click, describe the
  problem, and let the AI adjust it.
- **Keep refining in place.** After a quick edit lands, the AI sidebar opens
  with the same conversation ready to go, so you can keep asking for tweaks
  without starting over.
