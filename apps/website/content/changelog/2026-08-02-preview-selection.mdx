### Improved

- **Clean, familiar selection controls.** Objects and the background frame now use slim white
  borders and compact white handles that stay readable over bright or dark footage.

- **Deliberate object picking.** A single click selects the background; double-click the text
  you want to work on to isolate it. Keyboard users can select the focused object with Enter
  or Space.

### Fixed

- **Timeline selections now appear on the video.** Select a text object in the timeline and
  its editable bounds immediately appear in the program monitor, ready to move, resize, or edit.
