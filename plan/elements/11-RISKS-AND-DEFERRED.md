## 2. Deferred on purpose

Each is a decision, not an omission. Reopening one needs a maintainer decision recorded here.

| Deferred                                                                        | Why                                                                                                                                                                                                                         | What would reopen it                                                                      |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Automatic grounding ("find the button and circle it" without the model looking) | Needs UI-element or text boxes from visual understanding (OCR / detection); no such tool exists                                                                                                                             | A poor measured hit rate in the EL4a/EL8 eval cases, or the shot ledger exposing UI boxes |
| AI-generated stickers                                                           | New generative provider: cost, safety, licence surface                                                                                                                                                                      | Maintainer request with a provider choice                                                 |
| GIPHY / Tenor / "trending" GIFs                                                 | Rights to user-uploaded content in monetised video                                                                                                                                                                          | A provider with clear commercial terms                                                    |
| Brand and social logos                                                          | Trademarks                                                                                                                                                                                                                  | Legal guidance                                                                            |
| Lottie at runtime                                                               | No deterministic permissive Python renderer with parity; Lottie can be a _build-time_ source for WebP                                                                                                                       | A parity-proven renderer                                                                  |
| Stroke draw-on (`drawOn`)                                                       | No consumer in the first slices; the raster route could carry it later (05 §5)                                                                                                                                              | Requested after EL7                                                                       |
| A declarative loop effect                                                       | Keyframes from a builder meet the need with no schema change (scope review, change 6)                                                                                                                                       | Loops that break under trimming in practice (R11)                                         |
| A second (TS) shape rasteriser pinned to the engine                             | The engine is the only rasteriser; TS draws tiles only                                                                                                                                                                      | The browser fallback in EL11, which is labelled approximate rather than pinned            |
| Templates (lower thirds, subscribe buttons, text + shapes + animation groups)   | A separate product surface                                                                                                                                                                                                  | After EL7, if requested                                                                   |
| Gradients, inner shadows, per-vertex editing of shapes                          | Breadth beyond the requested outcome (outline, glow and drop shadow come free via edge styles)                                                                                                                              | Demand after EL5                                                                          |
| Fluent "Color" HD sticker pack (512 px)                                         | +24–88 MB; 3D is the recognisable look                                                                                                                                                                                      | Users enlarging stickers                                                                  |
| Skin-tone pack                                                                  | Measured in the EL11 review: 310 toned emoji × 5 = 1,550 files, ≈ 37 MB; bundled it breaks the packaged-set (40 MB) and installer (400 MiB) budgets, and an on-demand pack needs EL10's download path                       | A user asking for tones, once EL10's download path exists                                 |
| Follow subject for stickers (EL11.5)                                            | Needs the maintainer's decision on MO-14 (a clip following a track: baked keyframes or a `Clip.transformTrack` field); `follow_subject` in masking refuses to move a clip by that decision                                  | MO-14 answered                                                                            |
| Elements in the browser build (EL11.6)                                          | A `Path2D` rasteriser would be a second geometry implementation (ADR 0190); stickers need a browser project that stores imported bytes                                                                                      | Real browser users, or an engine connection in the browser                                |
| Localised sticker search (CLDR annotations)                                     | English-only product today                                                                                                                                                                                                  | Localisation of the app                                                                   |
| Animated GIF/WebP **user imports** as animated images                           | Changes the probe's classification for every import; separate from the library                                                                                                                                              | A reported need                                                                           |
| Sticker flip/mirror                                                             | The engine transform has no negative scale; needs a render change                                                                                                                                                           | Request                                                                                   |
| Sticker speed / reverse for animated stickers                                   | Rare; loop from clip start covers the use                                                                                                                                                                                   | Request                                                                                   |
| Agent picture-in-picture with Pexels footage                                    | Needs its own measurement (EL9 does manual only)                                                                                                                                                                            | Evidence from EL9                                                                         |
| A second stock provider (Pixabay)                                               | One provider is enough until proven otherwise (ADR 0141 reasoning)                                                                                                                                                          | Pexels gaps reported                                                                      |
| Sound-effect stickers                                                           | Audio belongs to Sounds                                                                                                                                                                                                     | Request                                                                                   |
| Stickers over MCP (a `FRAMEPILOT_ELEMENTS_ROOT` materialiser)                   | Deferred, decided autonomously 2026-09-26 (EL8.5): it gives the MCP sandbox a second read root, which CLAUDE.md §5 reserves for the maintainer, and no MCP client has asked; over MCP the search offers shapes and says why | An MCP client that needs stickers, and the maintainer widening the sandbox                |
