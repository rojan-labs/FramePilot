# 08 — The rename: every surface "Stock" reaches

**Rule (D7):** rename everything a person reads; keep everything a saved project, a recorded run,
or another process depends on. A renamed persisted identifier is data loss with extra steps; a
renamed model-facing tool name breaks every recorded replay and golden.

Legend: **Rename** · **Keep** (with the reason) · **Alias** (new name, old value still accepted).

## 3. What projects, runs and other processes store — Keep

| Identifier                                                   | Where it persists                                                          | Why it must not change                                                                                 |
| ------------------------------------------------------------ | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Asset ids `stock_pexels_<remoteId>`                          | every saved `project.fp.json`, `brain.sqlite` rows, visual-index enrolment | renaming orphans the brain rows and breaks dedupe of already-downloaded items                          |
| `Asset.source.provider = 'pexels'`                           | saved projects (schema v20)                                                | provenance written then is a record of what was agreed then                                            |
| `sources.json` ledger entries                                | project media folder                                                       | download dedupe                                                                                        |
| `framepilot.view.leftTab` = `'stock'`                        | `localStorage`                                                             | aliased, not migrated (a migration of view state would be a second source of truth)                    |
| `pexelsApiKey` (`ai-config.ts:68`), `PEXELS_API_KEY` env var | desktop config, `.env`                                                     | the user's saved key must keep working; no env-var change means no `.env.example`/`turbo.json` change  |
| Quota store persistence                                      | desktop userData                                                           | observed quota survives the upgrade                                                                    |
| IPC channels `framepilot:stock:*`                            | preload ↔ main contract                                                    | internal, accurate (the Pexels channels), and a rename risks a preload/main mismatch for no user value |
| Tool names `search_stock`, `add_stock`                       | recorded runs, replays (`--replay`), golden manifests, skills, MCP clients | a rename breaks every recorded run and shifts goldens; the model already understands "stock footage"   |
| `DOMAIN_SUMMARY.sourcing` and the two tool descriptions      | model-facing prompt text                                                   | same; changing them is a prompt change with its own token/golden delta and no user benefit             |
| Logger scopes `desktop:stock`, `desktop:stock-quota`         | log filters and runbooks                                                   |                                                                                                        |
| ADR files 0138–0141, 0143, 0147–0150                         | history                                                                    | superseded where decisions change (new ADRs), never edited in place beyond a status line               |
| `plan/3rd-party-sourcing/photo-video/`                       | history                                                                    | gains a pointer to this plan                                                                           |
