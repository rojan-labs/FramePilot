# 12 — Surface coverage: every place Elements touches

This file answers one question: **is anything in the repository affected by Elements that the plan
does not name?** Each row is a surface (a module, a module family, a config, a document), what
changes there, the phase that changes it, and what proves it. Rows marked **no change** are listed
on purpose, so their absence is a decision rather than an oversight.

Audited 2026-09-26 on `98ea829a` by reading the tree (per-tool tables, registries, tests that iterate
`TOOL_REGISTRY`, CI workflows, packaging scripts, website content). When implementation finds a
surface that is not here, add a row in the same PR.

Legend — **Proof:** U unit/integration test · V cross-runtime vectors · O PX4 oracle row · E e2e ·
P perf budget · G regenerated golden/fixture diff reviewed · D doc · R desktop evidence run.
